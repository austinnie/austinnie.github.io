## 痛点：一个具体的麻烦

我是做独立产品开发的，一个人扛着从调研到上线的全链路。最近接了一个竞品分析+PPT输出的活儿，光前期资料收集和最终交付就折腾了两天。

具体流程是：先用 ChatGPT 或 Claude 搜资料、整理观点，再切到 Notion 或飞书里结构化内容，接着打开 PPT 模板手工粘贴、调排版，最后还得反复核对数据来源和逻辑链条。光是切换工具和上下文记忆就已经让人崩溃了，更别提中间还要等 AI 出结果时发呆刷手机。

这种活每月至少2-3次，每次加起来就是大半天。而且每次都得手动把各个环节串起来，很容易出错或者漏掉关键信息。


![illustration](/images/illustration_03.png)

## 之前我们是怎么做的

① 手动打开 Claude Code 或 ChatGPT 写代码辅助分析
② 切换至视频工具或截图工具处理素材
③ 再打开 SEO/研究工具收集数据
④ 手动整理报告并导出 PPT
⑤ 反复人工审核每个环节

整个过程笨拙且耗时，关键是每个环节都是孤立的，信息传递全靠人工搬运，很容易出错。

## 为什么最后选了这个项目

对比了两个方案：一是直接用 Cursor/Claude Code 写脚本自动化，但这类工具更多是辅助编码，跨工具协作能力有限；二是买现成的自动化平台（如 Zapier），但这类 SaaS 成本高，且每次都需要重新配置流程，灵活性差。

Orkas-AI/Orkas 吸引我的地方在于：它不是单一工具，而是一个本地运行的"AI 团队"，能把 Claude Code、ChatGPT 等多种 AI 能力串联起来，而且项目记忆可以跨会话保留——这点对我这种需要反复迭代的工作流很关键。免费试用 500 credits 也能降低尝试成本。

## 关键步骤

**第一步：安装并创建项目**
从 GitHub 下载 Orkas，macOS 和 Windows 都支持。创建一个新的项目，输入目标："生成竞品分析报告并输出 PPT"。这里要写清楚目标，因为 Commander 会据此拆解任务。

**第二步：配置规则与记忆**
在项目设置里填入工作规则（比如输出格式要求、品牌调性）和已有文件（过往报告作为参考）。这些会被 Commander 记住，下次继续这个任务时不用重复说明。

**第三步：设置 Auto-advance 定时任务**
开启 Auto-advance 模式，让团队自动推进下一个待办事项。如果只是日常调研类工作，可以设置每小时/每日/每周重复执行。

**第四步：观察并审核成果**
任务完成后，成果会返回供审核。Reviewer 角色会标记需要人工确认的部分，你只需要检查关键点即可。

**第五步：迭代优化**
如果某一步质量不够，直接告诉 Commander 调整，它会自动重新协调相关 agent 处理，不用从头再来。

## 跑完之后

按项目文档描述，Orkas 可以把一个复杂目标拆成多个待办事项，由 Commander 协调 specialist agents 协作完成。项目可以跨会话保留上下文，Auto-advance 模式让团队自动推进任务，定时自动化能重复日常例行工作。

对于"生成竞品分析报告并输出 PPT"这类任务，理论上 Commander 会先调用 DeepResearcher 收集数据，再由 ContentWriter 和 PptMaker 分别处理内容和幻灯片，最后输出成品供你审核。但我实际只做了基础测试，复杂任务的完整效果还需要根据 README 描述来理解——具体能省多少时间，没有实测数据，建议你自己试用。

## 适合谁 / 不适合谁

**适合：** 需要频繁做"调研+内容+汇报"复合型工作的自由职业者或小团队；希望在一个界面里协调多个 AI 工具的人；不想每次重新配置流程、需要项目记忆的场景。

**不适合：** 只需要单一 AI 辅助编程的开发者（直接用 Cursor/Claude Code 更高效）；追求开箱即用、不想花时间配置工作流的；对数据安全有极高要求、无法接受任何第三方服务（Orkas 本身是本地运行，但内置模型可能需要联网）。
