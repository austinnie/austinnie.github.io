最近我在做一个新账号，每周都要产出一条长视频，发在 B站、抖音、小红书三个平台。每次录完播客，最头疼的不是内容本身，而是把它切成十几个短视频。


![illustration](/images/illustration_02.png)

## 痛点

我要从两小时的正片里挑出最有价值的几分钟——找金句、看节奏、听逻辑。找到之后，得逐条重新剪一遍，加上字幕，再单独做一张封面。更崩溃的是，同一个片段在 B站和抖音上要切两个比例，抖音还得做方图和小红书的封面，还要分别写文案。

一套下来，一个原本半小时的内容，能磨掉我大半天。而且越做越疲劳，质量反而不稳定。


![illustration](/images/illustration_03.png)

## 之前我们是怎么做的

流程大概是：先把原始长视频下载到本地，再用剪辑软件逐帧精剪精彩片段，接着给每条短视频手写或逐个导入字幕文件，随后用 Canva 之类的工具做封面，最后把视频裁剪成不同尺寸，填好各平台的标题和标签一个个上传。六七步走下来，每一步都在重复劳动，而且哪一步没对齐，后面就得重来。

那种笨拙感，就是你知道有更好的方式，但就是不知道是什么。

## 为什么最后选了这个项目

我其实看过两套替代方案。第一套是在线剪辑平台，有些能自动识别精彩片段，但大多要付费订阅，而且数据全在别人服务器上，对隐私比较敏感的题材不太放心。第二套是自己写脚本，理论上灵活，但要啃 FFmpeg、调参数，花的时间比自己剪还多，性价比太差。

这个项目不一样。它是本地运行的桌面工具，代码开源在 GitHub，数据不出本机。贴个 YouTube 或 B 站的链接，选好目标平台，就能自动生成竖版视频、字幕、封面和文案。不需要额外的付费订阅，免费版就能先用起来。最重要的是，它明确说适配抖音、小红书、TikTok、Reels、YouTube Shorts 这些我需要的平台，直接击中了我的痛点。

## 关键步骤

第一步，下载安装桌面客户端。它支持 Windows 和 macOS，从 GitHub Releases 下载最新正式版就行。

第二步，启动程序，在输入框粘贴长视频的 URL。支持 YouTube 和 B 站。

第三步，选择目标平台和输出比例，默认是竖版 9:16，也支持横版或其他比例。

第四步，点击生成，系统会自动下载视频、提取音频、识别精彩片段、生成字幕，并配上封面图和发布文案。

第五步，生成的结果可以在内置编辑器里微调，比如调整字幕样式、替换封面截图，或者重写某一条文案。改完后重新渲染即可导出。

整个过程我没有全部亲测，但 README 里描述的流程大致如此，核心操作就是通过 GUI 完成配置然后点生成。

## 适合谁 / 不适合谁

这个项目适合一个人同时运营多个平台的内容创作者，尤其是产出播客、访谈、课程类长视频的人。如果你每周都有大量长内容要复用，它能帮你省去很多重复劳动。

但如果你对实时性要求很高，比如热点新闻类内容，可能不太合适，因为云端模型需要时间处理，而且按量计费。另外，如果你的素材全是私有资源不能公开链接，也需要考虑这一点。
