## 痛点

我是全职打工，晚上偶尔看看盘、做做波段。每天要做的事其实就几件：看一眼大盘和持仓的风险状况、翻一翻有没有符合自己规则的新机会、记一笔交易理由和结果。但问题在于，这些东西散落在各处——券商 App、Excel 表格、甚至脑子里的念头，没有任何一个统一的入口把它们串起来。每次要做一个决定，光是把信息凑齐就得翻半天，平均要花 40 分钟到一个小时。更头疼的是，因为没有固定的流程，我经常漏掉该看的数据，事后也说不清当时为什么做出了那个判断。


![illustration](/images/illustration_03.png)

## 之前我们是怎么做的

最早我完全靠脑子加 Excel，每天打开表格填当天的涨跌和买卖理由。大概坚持了两周，有两个问题浮出水面：一是数据太琐碎，填起来比看盘本身还累；二是每次翻开记录，发现根本看不出自己的决策规律，因为缺少结构化的回顾框架。后来尝试在 TradingView 上用技术指标配合一个简单的工作清单，勉强能把每天的观察写进去，但要手动把数据搬过去，一周后我又回到了原点。

我也试过直接用大模型帮我分析市场，问它今天能不能买某只股票。回应用得很快，但问题来了——它替我做判断，我变成了被动接受的一方。这和我想要建立的自主决策流程背道而驰。后来有人提到 tradermonty/claude-trading-skills 这个项目，说是专门给没时间但有纪律需求的个人投资者用的，我就把它拿来看了一眼。

## 为什么最后选了这个项目

我对比了两个方案。第一个是自建 Python 脚本，网上能找到不少现成的 screener 和 portfolio tracker 代码，看起来可以按需拼装。但实际研究之后我发现，这类方案的门槛不在代码本身，而在后续的维护和整合——每一块独立跑没问题，要让它真正串联成一个完整的流程，投入的时间比我预期得多。另一个方案是用 AI signal service，也就是直接把选股和买卖信号交给模型输出。我用过一次就知道不行，那等于把决策外包给了黑盒，和本文的初衷完全冲突。

claude-trading-skills 吸引我的地方在于它的定位非常清晰：不提供买入卖出建议，而是帮你建立一套结构化的工作流程——市场分析、风险管理、交易记录和持续改进都在这里边。更重要的是，它允许从免费路径起步，不必一开始就接入付费 API，这让试错成本几乎为零。

## 关键步骤

第一步是在本地装好 Claude Code 和相关技能包，按照 README 的安装指引操作即可。这一步的目的是把整个项目的技能模块和预设工作流拉取到位。

第二步是选择一个起始工作流。我选了 daily market check，对应文档里的 `market-regime-daily` 工作流。这一步的作用是确定你每天用来做市场审查的最小闭环。

第三步是执行命令，大致是：

```bash
claude --workflow workflows/market-regime-daily.yaml
```

这里不用贴完整代码，关键是理解这条命令在执行什么：它会自动调用几个 skill，包括 market-breadth-analyzer（市场宽度分析）、uptrend-analyzer（上升趋势检测）和 exposure-coach（风险敞口指导）。每一步的输出都会被记录，方便后续回溯。

第四步是在每次执行前确认输入参数，确保你的持仓数据和风险偏好被正确读取。这不是可有可无的步骤，因为后续的分析结果都会基于这部分输入生成，如果输入错了，后面全白搭。

第五步是把当次的检查结论保存下来，形成一份可追溯的交易日志。README 里提到可以通过 `trader-memory-core` 来维护这部分内容，这样你之后回看的时候就有据可依。

## 跑完之后

按项目文档描述，这套流程可以帮助你建立结构化的市场审查、风险管理、交易计划和持续改进流程。具体来说，每日的检查路径不需要额外的 API Key，适合刚开始跑通流程的阶段；每周的长期投资组合回顾则需要接入 Alpaca 或手动导入 CSV 数据来完成持仓分析。文档还提到 swing-opportunity-daily 这条工作流，用于在市场允许的情况下筛选波段候选标的，它会调用 vcp-screener、drawdown-circuit-breaker 等 skill 来控制风险边界。trade-memory-loop 则专注于记录每一笔已平仓交易，帮助你从中学习。

至于月度的 performance review 和回测验证，按文档描述可以支持你定期回顾整体表现并调整规则，但这部分内容我还没来得及深入测试，有兴趣的同学可以自己试试。

适合谁：时间有限的个人投资者、以 ETF 和分红股为核心持仓同时想做波段补充的人、希望建立结构化投资流程而非依赖 AI 代劳判断的交易者。

不适合谁：追求全自动交易的程序员、想直接拿到买卖信号的人、高频短线交易者。
