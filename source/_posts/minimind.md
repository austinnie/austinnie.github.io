## 痛点

手头只有一块 RTX 3090，想真正搞懂大模型是怎么从数据里"学会"东西的，却发现基本走不通。动辄上百亿的参数摆在那里，别说自己从头训一个完整的全量模型，就算租一台云主机也要花好几百上千，时间更是按天计。平时做的探索几乎都停留在用 LoRA 对现有百亿参数模型做少量微调——加载、配个 adapter、跑几步就完了。问题在于，这样做完全摸不到训练底层的代码逻辑，黑盒使用，没法理解 attention 怎么转、loss 怎么降、tokenizer 为什么那么切词。每次遇到这类问题只能靠猜和搜文档，学习成本极高，调试周期动不动就是三五天起步。


![illustration](/images/illustration_03.png)

## 之前我们是怎么做的

1. 先想到的是租 GPU 集群或调云端 API，算下来一顿操作几百块打底，而且大部分时间在等待资源排队。
2. 退而求其次用 HuggingFace 生态，十几行代码拉个大模型、喂点数据、跑 LoRA 微调，流程看着很快，但实际上什么都没改变。
3. 偶尔想看底层实现，打开 transformers 源码直接放弃，层数太深，根本对不上自己的理解。
4. 从来没从零亲手写过训练循环，所以对 forward/backward/dataset pipeline 这些环节完全没有体感。
5. 想学点理论就去翻 paper，结果发现没有代码对照，数学公式看得头疼，实操环节依然接不上。

## 为什么最后选了这个项目

对比过两个方案：一个是直接用 transformers + trl + peft 搭一套标准 LLM 训练流程，另一个是看一些付费课程里的迷你模型教程。前者虽然接口成熟、上手快，但学到的只是"怎么用工具"而不是"工具怎么工作的"，跟我想要的目标背道而驰。后者内容参差不齐，很多讲得半懂不懂，还藏着大量营销话术，花时间看了也没法真正动手。minimind 正好踩在中间位置——它把所有核心代码从 PyTorch 原生写起，不设抽象层，把 Pretrain / SFT / LoRA / DPO 整个链路摊开给你看，同时 README 明确写了"只需不到 3 块钱成本 + 2 小时"就能在单张 3090 上跑通 64M 参数的 MiniMind。这个门槛对我来说足够低，又足够真，所以决定直接用它来走完一遍完整流程。

## 关键步骤

**第一步：准备环境与数据。** clone 仓库，配置 Python 依赖，README 里提供了清洗过的高质量数据集链接，按说明下载后放到指定目录。这一步的核心是确保 tokenizer 和样本数据对齐，不然后续预处理会出问题。

**第二步：跑通 Pretrain 阶段。** 用仓库提供的最小配置脚本，启动一个约 64M 参数的 Dense 模型进行预训练。README 标注了这是基于 Qwen3 结构对齐的版本，代码里能看到完整的 mask、loss 计算和梯度更新逻辑。这一步是为了让模型先学会语言的基本概率分布。

**第三步：做 SFT 监督微调。** 切换数据集和训练脚本，进入指令跟随阶段。同样是单卡跑，README 明确提到这一阶段耗时约 2 小时（1 epoch）。这里能清楚地看到模型如何从"预测下一个 token"转向"按指令输出"。

**第四步：跑 LoRA 和 DPO。** 分别在已有 SFT 权重上加 adapter 做高效微调，然后用拒绝采样/偏好数据训练 DPO 损失。这两步对应 README 中列出的 RLHF-DPO 链路，能直观感受到 reward model 信号是如何被转化成 loss 的。

**第五步：推理验证。** 导出 checkpoint，用兼容方式加载到 ollama / vLLM 等引擎里做交互测试。README 有在线体验链接可以参考效果形式，我自己本地也尝试跑通了一次基础对话。

## 跑完之后

按项目文档描述，64M 参数的 MiniMind 能在单卡上跑完上述全部阶段，覆盖数据清洗、Pretrain、SFT、LoRA 和 DPO 的完整链路，最终得到一个可交互的小模型。按照 README 的说法，它的体积约为 GPT-3 的一千分之三左右，核心价值不在于性能碾压，而在于让你完整经历一次"从 0 到 1 造轮子"的过程。文档中也提到了后续扩展方向，包括视觉版 MiniMind-V、多模态 Omni、扩散语言模型和线性模型变体，感兴趣的话可以继续往里钻。至于具体评测分数、推理延迟数字等实测指标，我没有单独跑，暂时不提。

## 适合谁 / 不适合谁

适合刚接触 LLM、想在本地 GPU 上亲手走完训练全流程的个人开发者和学生党；不适合追求生产级效果、想要跑大参数量模型并立即上线部署的工程团队。这个项目更像是一个教学性质的复现起点，而不是一个拿来即用的模型服务。
